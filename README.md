# 八卦弈魂 · BAGUA DUEL 64

两个人面对面，中间一张八卦盘；开局纯黑，方位随机。八席对应八属性/五行。每人 4 个属性 × 8 张人物牌 = 32 张牌库，每局随机取 2 属性 × 4 张 = 8 张出战；场上最多 3 张。牌位固定，每轮只刷新场地，不再顺时针轮转。

## 运行

```bash
cd wuxing
python3 -m http.server 8790
# http://127.0.0.1:8790/
# 手机：http://本机IP:8790/mobile.html
```

无构建工具、无依赖；`file://` 也能打开。

## 一局的流程

1. 开局随机坐向：坐北朝南者先手。
2. 每回合可以：
   - 落 1 张人物牌（新牌当回合不能行动，但可以被攻击）；
   - 场上每张牌各行动一次：攻击 / 获得一件装备 / 移动到相邻空位 / 仓促或坚守防御，四选一；
   - 使用最多 2 张不同技能。每张技能整局限 2 次。
3. 一方 8 张人物牌全部失去即负。

## 落子入场加成（移动不触发）

- 牌属性与席同五行：+2 攻 / +4 血
- 席生牌：+4 血
- 席克牌：-2 攻
- 家庭物象与席同五行：+2 攻 / +4 血

## 场地（每轮开始触发）

按“卦位五行 vs 牌五行”：

| 卦位 | 相生（卦位生牌） | 同五行 | 相克（卦位克牌） |
|---|---|---|---|
| 金 | 本回合伤害 +1 | 伤害 +1 | 伤害 -1 |
| 木 | 回复 1 血 | 伤害 +1 | 无 |
| 水 | 2 临时护盾 | 伤害 +1 | 无 |
| 火 | 攻击附加灼烧 2 回合 | 伤害 +1 | 自身灼烧 |
| 土 | 受伤 -1 | 伤害 +1 | 受伤 +1 |

灼烧每轮开始 -1 血，持续 2 回合，不叠加、刷新持续时间。临时护盾在轮结束时失去。

## 战斗

- 空手 / 近战 / 盾牌：距离 1；远程与长枪：距离 2。
- 相生正常；克制方对被克方伤害 +1；无反击。
- 护盾先挡，再算场地减伤/增伤；防御状态使受到的攻击伤害减半。仓促防御只持续到对手回合结束，回到自己回合消失并进入一回合防御冷却；坚守防御持续到手动解除，解除消耗该单位本回合行动。

## 8 件武器

| 武器 | 类型 | 效果 |
|---|---|---|
| 刀 | 近战 | 攻 +4 |
| 剑 | 近战 | 攻 +3，血 +4 |
| 斧 | 近战 | 攻 +6，血 -6 |
| 长枪 | 近战 | 攻 +3，距离 2；攻击一次后销毁 |
| 铁盾 | 盾 | 攻 -2，血 +6，每回合刷 4 盾 |
| 钢盾 | 盾 | 血 +2，每回合刷 3 盾 |
| 弓 | 远程 | 攻 +1，距离 2 |
| 弩 | 远程 | 攻 +2，血 -3，距离 2 |

武器生命不参与「险」的翻倍/减半。装备不可替换，除非「承载」。

## 8 张技能

刚健 / 口舌 / 光明 / 动 / 入 / 险 / 止 / 承载。技能目标带对应属性或家庭成员时增强；每张整局 2 次，每回合最多 2 张且不能重复。

## 人机难度

开始界面可选 简单 / 普通 / 困难，影响 AI 的技能使用、击杀优先级、落子加成与走位。

## 角色与局外弈魂

开始界面可选角色。道童、清风道长、旁门道人开局可选；痴儿需道童卜卦连续三次老阴解锁。角色选择、解锁、三魂七魄和局数按账号道号保存在 localStorage，未登录用 guest。

- **道童**：求签每回合 1 次，系统按双方人数、气血、攻击、场地与场面强弱判上上/上吉/中吉/中平/下下；卜卦每回合 1 次，三背老阳伤敌，三字老阴伤己，少阳、少阴无事。两项不占人物行动、不耗技能卡次数，签文只在角色面板显示。
- **清风道长**：化身（每局 1 次）选天地人一魂，木属性、不占 3 张上限，基础 20/40；天魂 30 攻、人魂 52 血、地魂 30% 追攻。分身（每局 1 次）选七魄之一，金属性、占 3 张上限，基础 20/30。两者不可同时在场；化身阵亡失去对应魂，三魂尽失本局判负；分身阵亡该魄转伪。
- **旁门道人**：被动炼魂，每回合开始己方场上 +1 攻 / -2 血；胜利结算时若己方场上仍有 3 张，可把一个已空缺的魄位炼为伪魄。
- **痴儿**：蠢笨 + 愚痴使己方受伤 -4；愚钝隐藏最佳落位提示；痴戾每回合最多 2 张己方牌攻击，这两次 +2 伤害。痴傻把失魂/失魄的缓冲延长 1 局。

## 局外流程

- 人物是局外选择：每关开始前选一次，关内锁定；过关或本关失败后回到选关界面可重新选人。
- 每局入座后随机取 2 属性 × 4 张出战，不再有手动选牌流程。
- 战败结算：失一魂或失两魄（三魂至少留一），可自行选择具体失去哪一魂、哪两魄；三魂七魄按剩余数量显示。
- 失魂/失魄在缓冲期提供增益，缓冲结束后转为减益；具体修正由 `src/meta.js` 的 `gameMods()` 注入对局。
- 献祭窗口：消耗当前牌库的一个属性 4 张；累计 2 次可炼伪魂，累计 1 次可炼伪魄，伪魂伪魄清除对应失魂/失魄效果。累计献祭 4/6 次降低入场攻血。
- 关卡内部多小局循环：每小局结束进入失魂/失魄和献祭结算，魂灯未熄就继续下一场；一方魂灯熄灭即本关结束，回到选关。三魂七魄每关重置。
- 账号存档：`Meta` 按 `bagua.meta.v2.<道号>` 存储；账号导出/导入同时包含局外存档。

## 防御辨识

场上牌的红/青左边条表示归属；每张牌所在卦位右上角另有“我”“敌”小标。进入仓促/坚守防御后，牌横置、保留“我/敌”标并加金色“守”标，避免横置或牌位变化后分不清敌我。牌位已经固定，不再轮转。

## 解释

- 「每个回合开始触发」按每轮（双方各一手）触发一次处理，临时护盾持续整轮，这样水席的护盾能挡到对手回合。
- 装备（普通给予）算该牌本回合的行动；「承载」换装不占行动。
- 技能「动」的两项匹配会额外让你选一个相邻友军 +1 行动。
- 「止」先选自己的牌，再选它范围内的一名敌人。
- 天气/节气只保留画面与提示，不再叠加全局数值，避免和场地效果冲突。

## 行动可读性

- AI 回合拆成“意图 → 执行 → 结果”，每步有播报、棋盘高亮、步骤条；5–8 秒内完成，可点「加速」。
- 技能/武器装备有中央播报，技能目标牌底生成像素粒子光效。
- 击杀弹出死因卡（基础伤害、盾挡、防御减半、实伤），AI 回合结束有「这一手」战报。
- 顶栏「菜单」可暂停、重新开始、回到主界面；继续 AI 回合会从当前步骤接上。
- 清风化身/分身使用过的单个魂/魄会进入一局冷却，下局不可选，再下一局恢复；每个魂/魄独立计算。
