# 八卦对决 · BAGUA DUEL 64

两个人面对面，中间一张八卦盘。八席对应八属性/五行，每人 32 张人物牌（4 属性 × 8 家庭成员），武器、八技能、十二建节气。

## 运行

```bash
cd wuxing
python3 -m http.server 8790
# http://127.0.0.1:8790/
```

无构建工具、无依赖；`file://` 也能打开。

## 牌与席

- 八席（后天八卦环序，顺时针）：离(火/南)、巽(木/东南)、震(木/东)、艮(土/东北)、坎(水/北)、乾(金/西北)、兑(金/西)、坤(土/西南)。
- 八属性：天(乾/金)、泽(兑/金)、火(离/火)、雷(震/木)、风(巽/木)、水(坎/水)、山(艮/土)、地(坤/土)。
- 八家庭成员：夫、少女、中女、长女、少男、中男、长男、母。
- 64 张人物牌 = 8 属性 × 8 家庭成员；开局随机 4/4 分给双方，各 32 张。
- 落子加成：
  - 牌属性与席同五行：+1/+1
  - 席生牌：+1 血
  - 席克牌：-1 攻
  - 家庭成员物象与席同五行：+2/+2
  - 当月月建五行与牌属性相同：+1 攻

## 行动

每手一次主行动：落一张人物牌 / 一张己方单位攻击一次 / 给一张己方单位一件装备。技能不占主行动，每手一次。

- 空手、近战、盾牌：攻击邻位（环距 1）；远程武器：环距 2。
- 装备不可替换，除非「承载」。盾牌每回合刷新护盾。
- 八技能：刚健、口舌、光明、动、入、险、止、承载。技能目标带对应属性/家庭成员时增强（匹配 0/1/2）。
- 方位随机：坐北朝南者先手；画面始终把玩家放在下方，对手在上方。
- 天气：十二建每回合轮转，当月五行 +1 攻，节气有全局效果；下一/再下一节气提前预告。

## 胜负

- 一方 32 张人物牌全部失去，立即结束。
- 否则一局一年（12 月建）；年末先比余下人物牌，再比场上人数、总血。

## 文件

- `src/data.js` 八席/属性/角色/64 牌/武器/技能/节气/占位肖像
- `src/engine.js` 对局引擎（落子、攻击、装备、技能、节气、AI 接口）
- `src/ai.js` 简单 AI
- `src/ui.js` 界面、天气层、交互
- `sim.js` 无头 AI 对局模拟
- `CHARACTER_PROMPTS.md` 64 张人物牌提示词（含 id 命名）

## 当前解释

- 技能按“每手 1 张”实现；“每张一回合限两次”若要改成每手可叠两张，调 `g.skillLeft` 与 UI 即可。
- 「有其一/有其二」按目标牌的属性/家庭成员各命中一项计 1/2。
- 「家庭物象与卦位五行对应 +2/+2」按角色所属卦的五行与席的五行比较。
- 「远程攻击 +2」按攻击距离 2 实现，不是伤害 +2。
- 人物牌基础攻/血为占位数值，等美术与平衡定稿后再调。
